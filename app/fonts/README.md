# Local fonts

These five OFL-1.1 fonts replace build-time Google Fonts requests. Inter is delivered as a small Latin subset and a full font. Each family includes its upstream license and metadata. `manifest.json` records the pinned Google Fonts commit, original TTF path and SHA-256, delivered WOFF2 SHA-256, version, axes, and loading settings. Original TTFs and Next build output are not vendored.

Conversion used fontTools 4.66.0 with WOFF2 support. Download each manifest `source` from `https://raw.githubusercontent.com/google/fonts/<commit>/<source>`, verify `sourceSha256`, then:

```python
from fontTools.ttLib import TTFont
from fontTools.varLib.instancer import instantiateVariableFont
font = TTFont(source_path)
axes = {axis.axisTag: axis.defaultValue for axis in font['fvar'].axes
        if axis.axisTag != 'wght'}
if axes:
    font = instantiateVariableFont(font, axes, inplace=True)
font.flavor = 'woff2'
font.save(output_path)
```

No glyphs are removed from the five full WOFF2 files. The remaining weight axis supports interpolation; the layout exposes the same individual weights as before (Inter exposes 100–900). Inter optical size is fixed at 14; Fraunces optical size at 9, softness at 0, wonk at 1; Bengali width at 100. These are the defaults requested by the previous Google loader, whose optional axes were not enabled. Font versions match the prior successful build.

Generate `inter/inter-latin.woff2` from the full Inter WOFF2 with fontTools 4.66.0:

```sh
pyftsubset inter/inter.woff2 --output-file=inter/inter-latin.woff2 --flavor=woff2 --unicodes=U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2190-2199,U+2211-2212,U+2215,U+2318,U+FEFF,U+FFFD --layout-features='*' --no-hinting
```

The subset contains only glyphs present in the original font within those requested ranges. It includes sampled Latin letters, accents, punctuation, arrows, the euro sign, and the homepage's command and summation symbols; it does not claim every code point in those ranges. The full Inter file remains in the CSS font stack after the subset for Cyrillic and other supported characters. Its `unicode-range` is the exact complement of the subset's cmap within the full Inter cmap (202 ranges, 2,555 code points), generated by coalescing consecutive code points. This keeps the full file deferred for every glyph covered by the subset. Regenerate that descriptor whenever the subset changes. `fallbacks.css` preserves the prior Google-loader fallback metrics exactly, after both Inter files. Local automatic metric calculation is disabled to avoid changing text sizing during swap.

Only the 70,328-byte Inter Latin subset is preloaded. Full Inter, Fraunces, Nunito, JetBrains Mono, and Noto Sans Bengali load when their glyphs or display modes are used. All six files total 679,092 bytes of available assets, while the root preload is 70,328 bytes.

Run `npm test -- lib/local-fonts.test.ts` for asset integrity and declaration regressions.
