# Toolblip Typography

## Font Stack
System fonts only — no web font loading:
```
font-sans: ui-sans-serif, system-ui, -apple-system, sans-serif
```

## Type Scale
| Class | Usage | Size target |
|-------|-------|-------------|
| `text-5xl` | Hero H1 | 48-60px |
| `text-3xl sm:text-4xl lg:text-5xl` | Page H1 | Responsive hero |
| `text-2xl` | Section H2 | 24px |
| `text-lg` | Card titles | 18px |
| `text-base` | Body | 16px |
| `text-sm` | Secondary text | 14px |
| `text-xs` | Labels, metadata | 12px |

## Spacing
- Hero padding: `py-14` to `py-20`
- Section padding: `py-10` to `py-12`
- Card padding: `p-4` (compact) or `p-5` to `p-6` (spacious)
- Grid gap: `gap-3` to `gap-4`

## Line Heights
- Headings: `leading-tight` (1.2)
- Body text: `leading-relaxed` (1.7)
- UI labels: `leading-none` (1.0)
