# Vercel Config Reference

## Current Configuration (next.config.ts)
```ts
images: {
  remotePatterns: [{ protocol: 'https', hostname: '**' }],
},
headers() {
  return [{
    source: '/(.*)',
    headers: [
      { key: 'X-Content-Type-Options', value: 'nosniff' },
      { key: 'X-Frame-Options', value: 'DENY' },
      { key: 'X-XSS-Protection', value: '1; mode=block' },
      { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
    ],
  }];
},
```

## Caching Headers (vercel.json)
Static assets cached at CDN edge. API routes use `Cache-Control: no-cache`.

## Image Optimization
- Next.js Image component auto-optimizes via Vercel CDN
- Remote patterns allow any HTTPS image source
- Use `priority` prop for LCP images (hero)

## ISR / SSR
- Pages are statically generated by default
- `export const dynamic = 'force-static'` forces static generation
- No `output: 'export'` — keeps Vercel ISR capabilities
