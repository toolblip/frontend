Every developer has a mental Rolodex of websites they rely on for quick tasks. These five are the ones you should actually keep bookmarked — not just saved in a random "dev stuff" folder you'll never find again.

## 1. JSON Formatter

When you're staring at a 3,000-line minified JSON response, your eyes need help. A good JSON formatter not only pretty-prints the data — it validates it, catches syntax errors, and highlights keys vs. values. Paste bad JSON and it tells you exactly where you went wrong. No more squinting at raw strings.

## 2. Base64 Encoder/Decoder

Base64 shows up everywhere — API authentication headers, embedding small binary assets, passing data in URLs. You need a reliable encoder and decoder that handles edge cases without mangling your data. Bonus points if it works with files, not just text strings.

## 3. Regex Tester

Writing a regex without testing it is a recipe for subtle bugs. A solid regex tester lets you input test strings, see matches highlighted in real-time, and understand what your pattern is actually doing. Look for one that explains capture groups and handles different regex flavors.

## 4. Cron Expression Parser

Cron syntax is notoriously cryptic. `*/15 9-17 * * 1-5` means something specific — but it takes a second to parse mentally. A cron parser converts expressions into human-readable descriptions and shows you the next N run times. Essential when scheduling jobs or debugging scheduled tasks.

## 5. Hash Generator

Need to quickly hash a string with MD5, SHA-1, SHA-256, or something else? A local hash generator lets you verify file integrity, test webhooks, or check password storage without sending anything to a server. All processing, all local.
