Every developer has a mental list of small utilities they reach for again and again. These are the tools that don't need a GUI, don't need an account, and don't need you to switch context to a heavy desktop app. Here are five you should have bookmarked.

## 1. JSON Formatter

Debugging JSON is one of the most common daily tasks in web development. A malformed comma, an extra bracket, and you're staring at a cryptic error for ten minutes.

A good JSON formatter validates your input, highlights syntax errors down to the character, and lets you collapse/expand nested objects. Some even let you sort keys, query with JSONPath, and diff two JSON objects side by side. Paste, format, fix, copy. Done in seconds.

Bookmark this one and thank yourself later.

## 2. Base64 Encoder/Decoder

Need to embed a data URI in a stylesheet? Pass a binary token through a URL parameter? Decode a Basic Auth header?

Base64 shows up in unexpected places. A dedicated encoder/decoder that handles UTF-8 properly — including emoji and international characters — is essential. Bonus points if it supports URL-safe Base64 variant and can handle file inputs, not just text.

## 3. Regex Tester

Writing a regular expression without testing it is a recipe for disaster. A good regex tester shows you exactly which parts of your test string match, which capture groups are active, and highlights syntax errors in your pattern.

Look for one that supports multiple flavors (JavaScript, Python, PCRE) if you work across stacks.实时看到匹配结果的能力让调试正则表达式变得完全不同。

## 4. Cron Expression Parser

Cron syntax is famously opaque. `*/15 9-17 * * 1-5` — that's every 15 minutes during business hours on weekdays, if you think fast. A cron parser that explains what your expression means in plain English, and shows you the next N run times, is invaluable for debugging scheduled jobs.

Whether you're configuring a CI pipeline, a serverless function, or a Linux cron job, a visual parser saves you from counting minutes in your head.

## 5. Hash Generator

MD5, SHA-1, SHA-256, SHA-512 — checking a file checksum, generating a password hash, or verifying an HMAC are all jobs for a hash generator. The best ones compute multiple algorithms simultaneously, accept both text and file input, and let you compare your result against an expected value with a visual diff.

All of these tools run entirely in your browser. No server, no upload, no data leaves your machine.
