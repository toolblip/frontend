Whether you're debugging an API response at 11 PM or spinning up a cron job for a side project, the right tool in your browser saves real time. This is a curated list of the best free developer tools available online — no signup, no install, no upload.

All of these run entirely in your browser. Your data stays on your machine.

## Text & Data Processing

### 1. [JSON Formatter](/tools/json-formatter)
Minified API response crashing your terminal? Paste it in, get pretty-printed JSON with syntax highlighting and instant validation. If there's an error, it tells you exactly which character caused it.

### 2. [Base64 Encoder / Decoder](/tools/base64)
Encode text to Base64, decode Base64 back to text, or convert a file to a Base64 data URL. Essential for HTTP Basic Auth headers, embedding small assets, and debugging token payloads.

### 3. [HTML Encoder / Decoder](/tools/html-encoder)
Safely escape HTML entities for embedding in source code, or decode HTML entities in scraped content. Handles all special characters including quotes, ampersands, and Unicode.

### 4. [YAML to JSON](/tools/yaml-to-json) & [JSON to YAML](/tools/json-to-yaml)
Convert between YAML and JSON formats instantly. Paste your config file, get the equivalent in the other format. Useful for Kubernetes configs, Docker Compose, and CI/CD pipelines.

### 5. [CSV to JSON](/tools/csv-to-json) & [JSON to CSV](/tools/json-to-csv)
Convert tabular data between CSV and JSON. Handles custom delimiters, headers, nested objects, and array formatting.

### 6. [TOML to JSON](/tools/toml-to-json)
Rust developers and Cargo users live in TOML. Convert TOML config files to JSON without leaving your browser.

### 7. [XML to JSON](/tools/xml-to-json)
Convert XML documents to JSON with options for attribute handling, array conversion, and pretty-print output.

### 8. [Hash Generator](/tools/hash-generator)
Generate MD5, SHA-1, SHA-256, SHA-384, and SHA-512 hashes from any text. Useful for verifying downloads, generating checksums, and working with APIs that require HMAC signatures.

### 9. [Hash Identifier](/tools/hash-identifier)
Paste an unknown hash and get instant identification of its type — MD5, SHA-256, bcrypt, and dozens more. No more guessing.

### 10. [JWT Decoder](/tools/jwt-decoder)
Decode JWT tokens without a library. See the header, payload, and signature separately, and verify if it's signed correctly.

### 11. [Regex Tester](/tools/regex-tester)
Test regular expressions against real sample text with live match highlighting. See capture groups, lookaheads, and backreferences visualized. Includes a pattern library for common cases.

### 12. [Regex Pattern Generator](/tools/regex-pattern-generator)
Describe what you want in plain English — "an email address" or "a US phone number" — and get a working regex you can copy directly into your code.

### 13. [Regex Cheatsheet](/tools/regex-cheatsheet)
Quick reference for regex syntax. Covers character classes, quantifiers, anchors, groups, and lookarounds with examples.

### 14. [Text Diff](/tools/text-diff)
Compare two text blocks and see added, removed, and unchanged lines highlighted. Faster than firing up a diff tool for a quick check.

### 15. [Code Diff](/tools/code-diff)
Same as text diff but with syntax awareness — understands code structure and highlights meaningful changes rather than just line-by-line differences.

### 16. [JSON Path Tester](/tools/json-path-tester)
Test JSONPath expressions against real JSON data. Specify your path query and see exactly which nodes it matches.

### 17. [JSON Schema Validator](/tools/json-schema-validator)
Paste a JSON document and a JSON Schema, get instant validation results with specific error messages for each violation.

### 18. [JSON Schema Generator](/tools/json-schema-generator)
Paste a JSON sample and auto-generate a matching JSON Schema. Start with valid data, derive the schema automatically.

## Developer Utilities

### 19. [Hash Generator](/tools/hash-generator) (also: [Hash Identifier](/tools/hash-identifier))
Already mentioned above but worth repeating — these two tools cover every hash-related task a developer encounters.

### 20. [Cron Expression Generator](/tools/cron-generator)
Build cron expressions visually with a point-and-click interface. See the human-readable schedule ("Every 15 minutes, Monday through Friday, 9 AM to 6 PM") next to the expression. Includes a next-5-runs preview so you can verify before deploying.

### 21. [Cron Expression Parser](/tools/cron-parser)
Reverse of the generator — paste a cron expression and get an instant human-readable explanation of what it means.

### 22. [UUID Generator](/tools/uuid-generator)
Generate UUIDs in bulk — v4 (random), v7 (time-ordered), or custom. Copy as plain text or JSON array. Useful for seeding databases and testing.

### 23. [Random IP Address Generator](/tools/random-ip-address)
Generate random IPv4 addresses, CIDR ranges, or IP ranges for testing firewall rules, access lists, and network configs.

### 24. [URL Slug Generator](/tools/url-slug-generator)
Convert any text into a URL-safe slug. Handles Unicode, removes special characters, and replaces spaces with hyphens. One click to copy.

### 25. [Slug Generator](/tools/slug-generator)
Another slug generator with more customization options — choose separator character, lowercase/uppercase, character limit, and preview the result.

### 26. [JWT Decoder](/tools/jwt-decoder)
Decode and inspect JSON Web Tokens without a library. See header alg, payload claims, and expiration time at a glance.

### 27. [ENV Parser](/tools/env-parser)
Parse `.env` file contents and see the key-value pairs formatted. Validate your env files before committing.

### 28. [Shell Command Generator](/tools/shell-command-generator)
Describe what you want in plain English — "find all files modified in the last 7 days" — and get the equivalent shell command you can copy and run.

### 29. [Shell Command Reference](/tools/shell-command-reference)
Quick reference for common shell commands with examples. grep, awk, sed, find — all with copyable snippets.

## Image Tools

### 30. [Image Resizer](/tools/image-resizer)
Resize images to standard dimensions (social media sizes, thumbnails, og-images) with aspect ratio lock. Batch resize multiple images at once.

### 31. [Favicon Generator](/tools/favicon-generator)
Upload any image or paste an emoji, get a complete favicon set — ICO, PNG at multiple sizes, SVG — ready to download and use.

### 32. [Image to Base64](/tools/image-to-base64)
Convert images to Base64 data URLs for embedding directly in HTML, CSS, or JSON. No server needed.

## Text Analysis

### 33. [Word Counter](/tools/word-counter)
Count words, characters, sentences, paragraphs, and reading time. Shows keyword density and most frequent words.

### 34. [Character Counter](/tools/character-counter)
Count characters with and without spaces. Essential for social media post character limits, meta descriptions, and code.

### 35. [Text Sorter](/tools/text-sorter)
Sort lines alphabetically, reverse alphabetically, by length, randomize, or remove duplicates. One click for each operation.

### 36. [Remove Duplicate Lines](/tools/remove-duplicate-lines)
Paste a list, get only unique entries. Sort option included. Faster than Excel for quick deduping.
