Every time you upload an image to "optimize" it on a free web tool, you're sending that image to someone else's server. For a random photo, that's probably fine. For a screenshot with sensitive data, a document with personal information, or assets you're not ready to share — it's a problem you didn't know you had.

Browser-based image processing solves this by doing all the work where you are: in JavaScript, on your device, using the Canvas API, WebAssembly codecs, and modern browser capabilities. Nothing leaves your machine.

**Cropping and Resizing**
The Canvas API lets you draw a portion of an image (or the whole thing, scaled) into a canvas element, then export it. It's been in browsers since forever and works at native-like speeds. Cropping to exact pixel dimensions, resizing to specific aspect ratios, even rotating — all without a server round-trip.

**Format Conversion**
JPEG, PNG, WebP, AVIF — each has different tradeoffs. JPEG is smaller for photos but loses quality. PNG supports transparency but is larger. WebP and AVIF offer the best of both but with varying browser support. A browser-based converter lets you experiment with output formats and quality levels side-by-side, seeing the file size difference immediately, without uploading anything.

**Compression**
Tools like Squoosh (Google's open-source image compressor) run entirely in-browser using WebAssembly builds of libvips, guetzli, and other codecs. You get good compression without giving up your originals to a third-party server.

**The practical upshot:** you can batch-process a folder of images, convert a dozen PNGs to WebP for a website, or resize profile photos before a presentation — all with zero upload risk and zero accounts.
