Every developer has a mental stack of sites they keep open in tabs for "just in case." Here are five tools that earn their bookmark status — fast, free, and running entirely in your browser.

**1. JSON Formatter**

When an API response comes back as a wall of minified text, a good JSON formatter is worth its weight in debug time. The best ones let you paste, validate, prettify, and even query specific paths — no copying into a terminal required.

**2. Base64 Encoder/Decoder**

Encoding tokens, embedding small payloads, or decoding something from a header — Base64 comes up constantly. Browser-based encoders process everything locally, so your data never touches a server. Essential for working with API auth, image data URIs, or debug sessions.

**3. Regex Tester**

Writing a regex blind is a fast path to frustration. A good regex tester shows you matches in real-time as you type, highlights capture groups, and explains what your pattern is actually doing. Some even generate common patterns for you — useful when you can't remember the exact syntax for "alphanumeric with dashes."

**4. Cron Expression Parser**

Cron syntax is famously unreadable at a glance. `*/5 9-17 * * 1-5` — is that every five minutes between 9am and 5pm on weekdays, or something else? A cron parser translates the expression into plain English and shows you the next N execution times. No more guessing.

**5. Hash Generator**

MD5, SHA-1, SHA-256, SHA-512 — sometimes you just need a hash of a string or file. Browser-based generators handle text input directly and can process small files without uploading anything. Useful for checking file integrity, generating checksums, or working through auth implementations.
