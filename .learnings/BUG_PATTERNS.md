# Bug Patterns — Recurring Issues & Their Fixes

## Bugs Encountered

### Environment Variables
- **Bug:** App crashes silently when env var is missing at runtime
- **Fix:** Validate all required env vars at startup; throw descriptive error if missing
- **Prevention:** Create `.env.example` with all required vars documented; check on startup

### Railway Deployment
- **Bug:** Build fails after merge due to missing dependencies not in `package.json`
- **Fix:** Always run `npm install` locally before pushing if adding any dependency
- **Prevention:** Lockfile changes (`.package-lock.json` or `yarn.lock`) must be committed with dependency changes

### Next.js Hydration
- **Bug:** Hydration mismatch errors caused by `Date.now()` or `Math.random()` in server components
- **Fix:** Move date/random logic to `'use client'` components or use `useEffect` for timing
- **Prevention:** Never use non-deterministic values in server-rendered markup

### CORS Issues
- **Bug:** API requests from frontend fail with CORS error
- **Fix:** Set explicit CORS origins in Laravel/Caddy; don't use `*` in production
- **Prevention:** Document allowed origins in `.env` and check before deploying

### Race Conditions
- **Bug:** Concurrent API writes cause double-submissions or inconsistent state
- **Fix:** Use database transactions; add unique constraints on idempotency keys
- **Prevention:** Identify idempotency keys for all write operations; test concurrent requests

### Image/API URL Mismatch
- **Bug:** Images break in production because hardcoded `localhost` URLs are in database
- **Fix:** Use relative URLs or environment-based base URLs; never store absolute URLs for assets
- **Prevention:** Base URL should come from env var; check in code review

### Soft Delete Confusion
- **Bug:** Queries return "deleted" records unexpectedly because soft delete scope isn't applied
- **Fix:** Always apply soft delete filter in find queries; use global scopes in Prisma
- **Prevention:** Document soft delete behavior; add tests that verify deleted records are excluded

### Session/Auth Token Expiry
- **Bug:** Users get logged out unexpectedly; tokens expire without refresh flow
- **Fix:** Implement token refresh on 401 response; warn user before expiry
- **Prevention:** Test token expiry scenarios; document token lifetime in `.env` comments
