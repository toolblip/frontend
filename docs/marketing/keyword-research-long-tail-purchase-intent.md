## Content Strategy by Intent

### Phase 1 — Launch Content (Target Informational)
Create how-to guides for top 5 tools that rank for:
- "how to [tool action]"
- "what is [tool concept]"
- "[tool] for [specific use case]"

### Phase 2 — Commercial Capture (Target Commercial)
After domain age builds, target:
- "best free [tool]"
- "[tool] vs [alternative]"
- "[tool] chrome extension"

### Phase 3 — Transactional (Target "Online" Keywords)
These are the easiest wins — users want a tool right now:
- Create clear, fast-loading tool pages
- Optimize for "no upload, browser-only" benefit
- Add structured data for rich snippets
