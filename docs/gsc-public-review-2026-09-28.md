# Public review of retained tool routes — 2026-09-28

## Public review decision

The [99-row Stage 1 source and content audit](gsc-remaining-review-2026-09-26.md) records each route’s purpose, worked example, limitations, source file and source hash. Its JSON companion records the original 99 decisions. Four exact duplicate routes were retired in deployed Stage 1 commit `d6e526056511bc2383780d46ca9880577429c875`; they stay redirects and are not promotion candidates. All 95 retained component hashes still match that audit.

The [per-route result matrix](gsc-public-review-2026-09-28.json) combines the full public HTTPS run (`/tmp/tb-stage1-public-full.json`) with the final scoped rerun (`/tmp/tb-public-fixture-targeted-final.json`). Each row shows Chrome and WebKit at 1440px and 375px, the Stage 1 source reference, and its decision rationale. The dedicated fixture checks tool-specific behavior, canonical URL, robots, hydration and horizontal overflow. The full run had **371 passes and 9 failures in 380 cases**. Four failures each were `temp-converter` and `passive-voice-detector`, caused by fixture assertions that did not match their accessible output. After those two fixture corrections, all **12/12** final scoped cases passed, including all four cases for each affected route.

The ninth full-run failure was `random-id-generator` on WebKit desktop. Its final scoped case passed, and five additional WebKit desktop repetitions passed with zero retries (`/tmp/tb-public-random-id-webkit-repeat.json`): six subsequent passes total. The Clear handler synchronously clears the generated IDs in source. Cookie consent interception appeared in the original failure context, but this evidence does not prove the cause. The matrix preserves the original failure and the later pass.

**Decision:** 92 retained routes have all four passing public cases, matching implementation-grounded Stage 1 review, and receive explicit reviewed decisions dated 2026-09-28. Three passing routes remain explicit holds: `gradient-generator` overlaps `css-gradient-generator`, `slug-generator` overlaps `url-slug-generator`, and `reading-level-estimator` overlaps `readability-score`. Their differences require separate consolidation decisions. The four retired aliases remain redirects. This is a local policy change; no new deployment or live indexing outcome is claimed. Search Console crawling and indexing require later measurement.
