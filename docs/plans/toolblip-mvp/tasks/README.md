# Tasks

Task groups live inside the stage files for now.

## Structure
- Task Group A: scope, discovery, prerequisites, verification setup
- Task Group B: implementation, tests, and final verification
- Task markers: todo, working, blocked, done, lean

## Lean rule
- If a task is too expensive or noisy for MVP, mark it lean instead of hiding it.
- Keep lean items attached to the feature so the decision can be revisited later.
