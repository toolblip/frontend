# Remaining 99 tool review: Stage 1

The original cohort was 444 catalog routes: 345 eligible and 99 excluded. Stage 1 retires four exact shared-engine duplicates. The resulting catalog has 440 routes, with 345 eligible and 95 excluded. The eligibility policy and its frozen 354-route legacy snapshot stay unchanged. This review does not promote any of the 95 routes.

Each row below records the user task, a worked case, a limit, and the Stage 1 decision. The JSON companion keeps the original 99 slugs, source hashes, individual pre-stage public QA attempts, and next actions. Public test results below predate these local repairs and cannot establish deployed behavior.

## Decisions

- Four exact duplicates retire to tested canonical targets: `hash-from-text` → `sha256-hash-generator`; `regex-description-generator` → `regex-explainer`; `google-serp-preview` and `google-serp-simulator` → `serp-preview`. The target follow-up had 11/12 Chrome/WebKit desktop/mobile checks pass; Chrome desktop SERP timed out. Local final redirect and target checks are recorded in the Stage 1 result.
- Three similar tools stay excluded because they are not exact equivalents: `gradient-generator`, `slug-generator`, and `reading-level-estimator`. Their output or controls differ from the proposed targets.
- The other 92 remain excluded for deployed functional and metadata review. Curated content is preparation, not indexing approval.

## Local Stage 1 checks

The final canonical-target run passed 12/12 Chrome and WebKit cases at 1440 and 375 pixels. The repaired-behavior run passed 39/40; the single cookie-consent double-click in the harness was removed, and that clock case passed in the focused follow-up. The follow-up passed 16/24, including Copy All, approximate BEM output, clock rollover and paragraph placeholders. All eight remaining cases depended on the local grammar API reaching its upstream service and failed there. The manual-edit offset regression passes in the component suite. Local HTTP checks confirmed seven one-hop 308 redirects with query strings preserved, 345 tool sitemap entries, and no retired URL in that sitemap. These results are recorded per route in the JSON companion and in `/tmp/tb-remaining-stage1-result.md`.
