Every developer has a graveyard of half-installed CLI tools, abandoned npm packages, and "I'll remember this site" tabs. Here's a better approach: bookmark the ones that actually work, and use them for years.

These are the five tools I reach for almost every day.

## 1. JSON Formatter & Validator

Debugging malformed JSON is a special kind of misery. A good JSON formatter takes the mess in your clipboard and gives you clean, indented output — plus tells you exactly where things went wrong. Bonus points if it validates as you type.

**Use it when:** Pasting API responses, debugging config files, or reading minified JSON in a bug report.

## 2. Base64 Encoder/Decoder

Base64 shows up constantly — in OAuth flows, API auth headers, data URIs, and JWTs. Having a quick encode/decode tool that works entirely in-browser means you never have to `echo "string" | base64` and hope you got the flags right.

**Use it when:** Inspecting JWT payloads, encoding icons for CSS, or debugging Authorization headers.

## 3. Regex Tester

Writing regex without testing it is like writing code without running it. A good regex tester shows you matches in real time, explains what your pattern is actually doing, and highlights capture groups. Some even generate common patterns for you.

**Use it when:** Writing validation logic, parsing logs, or trying to understand someone else's terrifying regex.

## 4. Cron Expression Parser

Cron syntax is famously opaque. `*/5 9-17 * * 1-5` — is that every five minutes, or every five hours? A cron parser converts the expression into human-readable text and shows you the next several run times.

**Use it when:** Scheduling CI jobs, configuring server cron, or reviewing scheduled tasks in a codebase you inherited.

## 5. Hash Generator

Need to quickly hash a string with MD5, SHA-1, SHA-256, or SHA-512? A local hash generator handles it in milliseconds. Since it runs in your browser, the input never goes anywhere — useful when working with anything even mildly sensitive.

**Use it when:** Verifying file checksums, generating password hashes, or checking if a string matches an expected HMAC.

These five tools cover the small, annoying tasks that interrupt deep work. Bookmark them once, and you'll save hours over the course of a year.
