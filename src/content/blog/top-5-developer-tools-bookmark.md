Every developer has a graveyard of small apps they installed for one task and forgot about. JSON formatter, Base64 encoder, regex tester — each one a 10MB download for a 30-second job. Here's a better approach: **bookmark these five categories of tools** and never install a one-off utility app again.

## 1. JSON Formatter & Validator

Pretty-printing JSON in your editor is fine for files you own. But for validating incoming API responses, debugging webhook payloads, or sharing formatted JSON with a teammate? A dedicated formatter highlights syntax errors, collapses nested structures, and lets you navigate large blobs without losing your mind.

Look for one that validates AND formats, so you catch malformed JSON before it bites you in production.

## 2. Base64 Encoder / Decoder

Encoding credentials for Basic Auth, embedding small images as data URIs, working with tokens from third-party APIs — Base64 shows up constantly but rarely deserves a full app. A fast browser-based encoder-decoder handles it instantly. Bonus points if it supports URL-safe Base64 variant.

## 3. Regex Tester

Writing a regex blind is a gamble. A good regex tester shows you exactly which parts of your test string match, what each capture group captures, and highlights errors in real-time. No more "works on my machine" regex bugs that only surface at 2am.

## 4. Cron Expression Parser

Cron syntax is notoriously hard to read. `*/15 9-17 * * 1-5` — wait, is that every 15 minutes during business hours on weekdays, or something else? A cron parser that humanizes the expression ("Every 15 minutes, 9am to 5pm, Monday through Friday") saves you from reading the man page for the hundredth time.

## 5. Hash Generator

Need to quickly verify a file checksum, hash a password for a config, or generate an HMAC for an API signature? A hash generator that supports MD5, SHA-1, SHA-256, and SHA-512 handles all of these. Look for one that works entirely in-browser — no server-side processing of your data.
