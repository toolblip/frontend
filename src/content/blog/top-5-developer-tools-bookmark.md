Every developer has a mental list of tiny utilities they use constantly but can never remember the name of. You Google it, find some sketchy site with a thousand banner ads, and pray it's not mining crypto in the background. Been there.

Here's the better approach: bookmark the good stuff once and be done with it. Here are five tools that deserve a permanent spot in your browser.

## 1. JSON Formatter

Raw JSON is basically unreadable. You squint at `{ "data": [ { "id": 1...` and immediately start scrolling, looking for the structure you actually care about. A good JSON formatter prettifies the output, highlights keys and values differently, and lets you collapse/expand nested objects. If you're still manually reading raw JSON, stop.

## 2. Base64 Encoder/Decoder

Base64 shows up in authentication headers, API responses, embedded images, and a dozen other places. Converting to/from it shouldn't require a Python one-liner every time. A quick web tool handles it instantly, with proper handling for UTF-8 strings that some command-line approaches get wrong.

## 3. Regex Tester

Writing regex without testing it is a special kind of optimism. A solid regex tester shows you exactly which parts of your test string match, highlights capture groups in different colors, and explains what your pattern is actually doing. Some even have a library of common patterns. No more "close enough, I'll debug it in production."

## 4. Cron Expression Parser

Cron syntax is famously unreadable. `*/15 9-17 * * 1-5` — oh cool, that's every 15 minutes during business hours on weekdays. Obviously. A cron parser converts the cryptic schedule into plain English and shows you the next N execution times. Essential for anyone who manages scheduled jobs.

## 5. Hash Generator

MD5, SHA-1, SHA-256, SHA-512 — you need to verify file integrity, check passwords against known breaches, or debug a checksum mismatch. A hash generator that handles files directly (without uploading to some server) is the way to go. Browser-based processing means your file never leaves your machine.

---

These five cover the boring, repetitive utility work that compounds over time. Every minute saved is a minute you can spend on actual problems. Bookmark them once, thank yourself forever.
