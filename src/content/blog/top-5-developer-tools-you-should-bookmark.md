Every developer has a mental folder of sites they return to again and again. For quick encoding tasks, regex debugging, and data transformation, here are five tools worth keeping bookmarked.

**1. JSON Formatter** — [/tools/json](/tools/json)

Debugging messy JSON is a daily annoyance. A good JSON formatter not only prettifies your data but validates it, catches syntax errors, and highlights keys vs values. No more squinting at single-line JSON in a terminal.

**2. Base64 Encoder/Decoder** — [/tools/base64](/tools/base64)

Encoding images, handling API auth headers, obfuscating strings — Base64 comes up constantly. Browser-based means no Python one-liners or terminal flags to remember. Paste, encode or decode, copy, done.

**3. Regex Tester** — [/tools/regex](/tools/regex)

Writing a regex without testing it is like writing code without running it. A regex tester with live match highlighting shows you exactly what your pattern matches, which groups capture what, and flags common mistakes — all without a page reload.

**4. Cron Expression Parser** — [/tools/cron-parser](/tools/cron-parser)

Cron syntax is notoriously cryptic. `0 8 * * 1-5` means 8 AM on weekdays, right? A cron parser that translates expressions into human-readable schedules and shows upcoming run times is invaluable when setting up scheduled jobs — and essential when debugging why something ran (or didn't).

**5. Hash Generator** — [/tools/hash](/tools/hash)

MD5, SHA-1, SHA-256 — sometimes you just need to verify a checksum, generate a hash for a password salt, or confirm a file's integrity. A multi-algorithm hash generator that works locally (no upload required) handles this cleanly.

---

These five cover a surprising amount of the small but frequent tasks that interrupt deep work. Bookmark them once, use them forever. And if you find yourself wishing one of these did something slightly different — let us know. We're always adding features based on what developers actually need.
