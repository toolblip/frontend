Every developer has a folder of random scripts and one-off scripts they reach for when the need arises. But honestly? Most of those needs are better served by a well-designed browser tool. Here are the five you should have bookmarked right now.

## 1. JSON Formatter & Validator

Debugging malformed JSON is a rite of passage every developer goes through. A good JSON formatter takes ugly, minified API responses and turns them into readable, syntax-highlighted output. Bonus points if it validates as you type and shows you exactly where your syntax went wrong.

**Use it for:** Debugging API responses, pretty-printing config files, finding that missing comma.

## 2. Base64 Encoder/Decoder

Base64 shows up constantly — encoding images for data URIs, passing tokens in URLs, embedding binary in JSON payloads. Needing this and not having it is genuinely painful.

**Use it for:** Embedding images in HTML/CSS, decoding JWT payloads, encoding file contents for APIs.

## 3. Regex Tester & Debugger

Writing regex without testing it live is like writing code without running it — brave, but risky. A good regex tester shows you matches in real-time, explains what each part of your pattern does, and helps you build complex expressions without the headache.

**Use it for:** Validating email formats, parsing log lines, extracting data from unstructured text.

## 4. Cron Expression Parser

Cron syntax looks like line noise until it clicks, and then you still can't read `*/5 0,6,12-18 * * *` without double-checking. A cron parser that explains what a schedule means in plain English — "every 5 minutes, between midnight and 6am, and noon to 6pm" — is invaluable.

**Use it for:** Setting up CI schedules, configuring server cron jobs, verifying that "every weekday at 9am" actually looks like `0 9 * * 1-5`.

## 5. Hash Generator (MD5, SHA-1, SHA-256)

Need to verify a download? Check a password hash? Generate an HMAC? A quick hash generator that handles multiple algorithms is surprisingly useful to have around.

**Use it for:** Verifying file integrity, generating secure tokens, checking password hashes.
